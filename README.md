# 课铃

根据《学生课表》制作的课程提醒网页，包含每日课程、周课表、课程时间与教室、提前 5/10/15/30 分钟提醒设置，并已加入 Android Chrome 网页应用清单和离线缓存。

## 启动

1. 双击 `启动课铃.command`。
2. 页面打开后，点击“启用浏览器通知”，并允许浏览器发送通知。
3. 选择提醒提前量，并保持这个网页打开。

关闭启动时出现的终端窗口会停止本地服务。下次使用时重新双击启动文件即可。

## 安装到 Android

先把整个文件夹部署到可通过 HTTPS 访问的网站，然后在 Android 手机上用 Chrome 打开网站。点右上角“⋮”→“安装应用”或“安装并创建快捷方式”→“安装”。

提醒由打开中的网页检查课程时间。安装图标和离线缓存不会自动提供锁屏后的定时提醒；手机暂停网页运行或系统休眠时，提醒可能延迟或不触发。若需要网页关闭后仍可靠推送，需要另加推送服务器和定时任务。
